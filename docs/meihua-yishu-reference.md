# 梅花易数 解卦参考手册

> 本文档由联网检索整理（2026-07-29），汇集梅花易数核心理论、断卦法则与经典案例，供"问春风"项目在解卦时参考引用。
> 主要来源：易象乾坤易学网（yixiangqiankun.com 梅花易数专栏）、搜狐·琴鹤堂国学《观梅占心易详解》、搜狐·新禹风水易道《李修真：梅花易数起卦、占断诀窍》。

## 一、源流与立论

- 《梅花易数》相传为北宋邵雍（字尧夫，谥康节，1011–1077）所传，以先天八卦之"数"为体、万物类象之"象"为用，随时随地起卦。
- 得名于"观梅占"：邵雍观梅见二雀争枝坠地，起卦断"明晚有女子折花、园丁逐之、女子惊坠伤股"，果验，遂以"梅花"名其术。
- 立论纲领：**"不动不占，不因事不占"**——必有所动、有所问方才起卦。
- 心易之说（《梅花易数·卷二·心易占卜玄机》）：同得《革》卦，不能每次都断"女子折花"。卦内体用生克之外，还须结合**起卦时的外应取象**（心易），二者相加才是完整的断法。占卜之道，要变通，"得变通之道者，在乎心易之妙耳"。
- 先天起卦（报数、时间）重卦气五行时令；后天起卦（物象、颜色、方位）重外应取象。

## 二、基础数序（起卦必备）

### 先天八卦数（卦以八除）
| 数 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|----|---|---|---|---|---|---|---|---|
| 卦 | 乾 | 兑 | 离 | 震 | 巽 | 坎 | 艮 | 坤 |

### 地支数（用于年、时）
子1、丑2、寅3、卯4、辰5、巳6、午7、未8、申9、酉10、戌11、亥12

### 五行与八卦
- 乾兑属金，震巽属木，坎属水，离属火，艮坤属土。
- 相生：金生水、水生木、木生火、火生土、土生金。
- 相克：金克木、木克土、土克水、水克火、火克金。

### 卦气旺衰（断吉凶、定应期的重要权重）
- 震巽木：旺于春，衰于秋。
- 离火：旺于夏，衰于冬。
- 乾兑金：旺于秋，衰于夏。
- 坎水：旺于冬，衰于辰戌丑未月（四季月）。
- 艮坤土：旺于辰戌丑未月（农历三、六、九、十二月），衰于春。
- 临月建为旺；月建生之为相（次旺）；克月建者休囚无力；月建克之为衰。
- 卦气强弱还看"党"：体卦之同五行者（本卦、互卦、变卦中出现）多则强，"党多气衰亦无碍，党少卦旺亦有伤"。

## 三、起卦法（项目已实现"三数起卦"，此处为完整对照）

### 1. 数字起卦法（先天起卦）
- 报 1~2 个数（1-10 或 1-49 随意）：第一数 ÷8 余数为上卦，第二数 ÷8 余数为下卦，两数之和 ÷6 余数为动爻。整除无余时按 8 或 6 算；小于 8/6 则直接用该数。
- 报 3 个数：一数上卦、二数下卦、三数之和 ÷6 取动爻（本项目即此法的变体）。

### 2. 年月日时起卦法（时间起卦）
- 上卦 =（年支数 + 月数 + 日数）÷8 取余
- 下卦 =（年支数 + 月数 + 日数 + 时数）÷8 取余
- 动爻 =（年支数 + 月数 + 日数 + 时数）÷6 取余
- 月日皆用农历数；时数取地支序（子1…亥12）。

### 3. 物象/颜色起卦（后天起卦）
按所见之物、颜色、方位直接取卦，再加时辰数取动爻。
颜色类象：乾—大赤/金，兑—白/银，离—红/花色，震—青绿，巽—蓝碧，坎—黑紫，艮—棕咖，坤—纯黄。

### 卦的结构
- **本卦（主卦）**：起出的原卦，代表事物初始、现状。
- **动爻**：发生阴阳变动的那一爻（自下而上数）。
- **变卦**：动爻阴阳翻转后所得之卦，代表事物后期、最终结果。
- **互卦**：本卦三、四、五爻组成上互卦，二、三、四爻组成下互卦，代表中间过程、隐秘之事。
- 错卦（全卦阴阳互变，反向思考）、综卦（旋转180°，换位思考）可作辅助参考。

## 四、体用断法（梅花易数断卦总纲）

### 体用划分
- **动爻所在的经卦为"用卦"**（为他人、为所占之事、为外因）。
- **无动爻的经卦为"体卦"**（为自己、为求测人、为事情主体）。
- 本卦=事之始，互卦=事之中（过程），变卦=事之终（结果）。

### 体用生克五诀（吉凶总纲）
| 关系 | 断语 | 吉凶 |
|------|------|------|
| 用生体 | 有进益之喜，他人助我 | **大吉** |
| 体克用 | 我占主动，事可成但费力 | **小吉** |
| 体用比和 | 百事顺遂 | **吉** |
| 体生用 | 有耗失之患，泄气 | **小凶** |
| 用克体 | 他人来克我 | **大凶** |

### 旺衰修正（重要）
体用生克只是框架，还须叠加上一时节的旺衰：
- 体卦宜旺相有气，不宜休囚死绝。体旺则虽克无惧，体衰则虽生难扶。
- 例（李修真卦例）：体克用变为用克体，本主先吉后凶；但体卦坎水得日月生助、卦中三坎成党，不畏艮土之克，反断"有克为有官升职之象，断吉"。
- 即：**生克定关系，旺衰定力量，党众定根基**，三者合参才能下断语。

## 五、经典案例（《梅花易数》原书占例）

### 案例 1：观梅占（时间起卦 · 成名之占）
- 背景：辰年十二月十七日申时，邵雍见二雀争枝坠地，曰"不动不占，不因事不占。今二雀争枝坠地，怪也"，遂占。
- 起卦：辰5 + 十二月12 + 十七日17 = 34，÷8 余 2 → 兑（上卦）；加申时9 得 43，÷8 余 3 → 离（下卦）；43 ÷6 余 1 → 初爻动。
- 得卦：**泽火革**，初爻变**泽山咸**，互见乾、巽。
- 断：明晚有女子折花，园丁不知而逐之，女子失惊坠地，伤其股。
- 理路：
  - 兑金为体，离火克之（用克体，凶）；
  - 互中巽木又生离火，克体之气更盛；
  - 兑为少女 → 知受伤者为少女；
  - 巽为股，巽木被互中乾兑之金所克 → 伤股；
  - 变卦艮土生兑金 → 但伤不至凶危。
- 应验：果如其言。
- **启示（心易）**：体卦兑可取象少女、妾、歌伎、巫师等多象，此处取"少女"，是结合"二雀争枝"的外应（雀=年少佳人、争枝=口舌）而定。同类外应取象，有史可征：
  - 《北齐书·张子信传》：二鹊斗堕 → 主口舌；
  - 《明史·皇甫仲和传》：见两鹊斗屋上 → 断卫士"妻妾正相斗"；
  - 清《字触》：汪龙以"少妇着孝服"取象"麻雀"。

### 案例 2：牡丹占（时间起卦）
- 背景：巳年三月十六日卯时，邵雍与客观牡丹，客问"花之盛衰亦有数乎"，遂占。
- 起卦：巳6 + 三月3 + 十六16 = 25，÷8 余 1 → 乾（上）；加卯时4 得 29，÷8 余 5 → 巽（下）；29 ÷6 余 5 → 五爻动。
- 得卦：**天风姤**，五爻变**火风鼎**，互见重乾。
- 断：此牡丹明日午时当被马践毁。
- 理路：
  - 巽木为体，乾金克之，互卦又见重乾，克体太过，巽木无生 → 花必毁；
  - 乾为马 → 践花者马；
  - 变卦离火为午、为光明 → 应在午时。
- 应验：次日午时有贵客观牡丹，二马相嘶奔于花丛，牡丹尽毁。
- **启示**：克体之卦多现（重乾），纵无动爻之卦亦成党助威；类象（乾=马）与时辰（离=午）皆从卦中直接取出。

### 案例 3：现代报数例（李修真 · 问仕途）
- 男问仕途，报"47"：上卦（年2+月10+日27+47）÷8 余 6 → 坎；下卦（再加时5）÷8 余 3 → 离；动爻总数 ÷6 余 1。
- 主卦水火既济（体坎水/用离火）→ 变卦上坎下艮。
- 断：体克用（坎克离）变为用克体（艮克坎），但坎水得日月生助且卦中三坎成党，不畏克，反主"有克为有官升职"，断近期有官运，春节前后升职。

### 案例 4：简易报数例（易象乾坤 · 问感情/生意）
- 女问恋爱，报 6、6：坎为水，六爻动 → 变风水涣。体用比和主早期融洽；互卦见矛盾渐生；变卦体生用（水生木）泄气，难成正果。
- 女问生意，报 2、8：地泽临，四爻动。体坤土生用兑金（泄）→ 难成；变卦体克用 → 迟吉、可成但多磨，条件不合则不成。
- 男问"女友何时出现"，报 23、27：23÷8 余 7（艮）、27÷8 余 3（离），和÷6 余 2，二爻动。主卦用离火生体艮土（吉，开始有人缘）；变卦体生用泄气（后不佳）→ 初恋不成，离数为 3，历三段感情方定。

## 六、断卦流程清单（供解卦逻辑参考）

1. **定体用**：看动爻在上卦还是下卦——动爻所在为用，另一为体。
2. **看本卦体用生克**（定现状吉凶基调）：用生体/比和为吉，体克用小吉，体生用耗，用克体凶。
3. **看互卦**（定中间过程）：互卦对体卦的生克，表示事情发展中的助力或阻力、隐情。
4. **看变卦**（定最终结果）：变卦对体卦的生克是一卦之归宿，权重最高。
5. **参旺衰**：以起卦月令定体卦及克体/生体之卦的旺衰，修正吉凶程度（旺体不惧克，衰体受生亦迟）。
6. **取类象**：按八卦万物类象取人、事、物、方位、时辰（如乾=马/父/首/金，兑=少女/口/泽，巽=股/长女/风木，离=午/目/火，坎=耳/水/险……）。
7. **定应期**（进阶，当前项目未实现）：
   - 先天起卦以卦气五行定应期：用生体者，应于生体之卦当值之日；体克用者，应于体卦当值或受生之日；
   - 变卦/互卦的卦数、卦的五行所主之时（如离=午、坎=子）皆可取应期；
   - 旺体遇生遇比皆吉，应事快；衰体应事迟。
8. **合外应**（心易）：起卦当下的声音、动静、人物、颜色等异常之象，与卦象互参。

本项目当前实现：三数起卦 → 本卦 + 动爻 + 变卦 + 动爻爻辞吉凶（`yao_fortune.ts`）。上表可补强的方向：

| 已有 | 可参考增强 |

| 动爻吉凶六档 | 叠加**体用生克五诀**给出第二层吉凶（用生体 / 体克用 / 比和 / 体生用 / 用克体） |
| 维度解读（事业/感情/财运…） | 引入**八卦五行类象**按维度取象（如问感情重看阴阳配、问财运重看生体之卦） |
| 时辰起卦（留空时） | 对齐正统**年月日时起卦法**（农历月日 + 地支时辰数） |
| —— | 可选：**卦气旺衰**按当前月令加权吉凶；**应期**提示（变卦/用卦所主之月日） |
| —— | 解卦文案可引用本手册案例的理路（观梅占的"体用+类象+变卦兜底"三段式） |

### 体用吉凶速查（代码实现用）
```
体卦五行 vs 用卦五行：
  用生体  → great-good（大吉，有进益之喜）
  比和    → good      （百事顺遂）
  体克用  → good      （小吉，主动可成但费力）
  体生用  → neutral/caution（耗失之患）
  用克体  → bad       （大凶）
```
八卦五行映射（与 types.ts 中 TrigramIndex 对齐）：
1 乾=金, 2 兑=金, 3 离=火, 4 震=木, 5 巽=木, 6 坎=水, 7 艮=土, 8 坤=土。
动爻 ≤3 → 下卦为用、上卦为体；动爻 ≥4 → 上卦为用、下卦为体。
